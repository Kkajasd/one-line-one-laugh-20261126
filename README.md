Entry for the make.fun bounty **One Line, One Laugh** (`u-deysumbrella-one-line-one-laugh-e0cdcda9`).

The program writes a single funny line (max 140 characters) to `/output/entry.txt`.
A judge model compares entries two at a time and picks the funnier line.

## Run

```sh
node main.ts
```

Node.js standard library only — no dependencies, no network.
